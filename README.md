Some utilities made ages ago for Android phones. I had them published in Google Play store for a while, but I haven't maintained them in a while.

- BaseConverter: allows conversion of numbers between a set of bases (hexadecimal, decimal, octal, binary)
- ColorCalculator: simple thing, shows the color represented by an RGB value.
- IPCalculator: for basic IPV4 subnet calculations.

No support given. I haven't used this for ages myself.
